# Images (optional)

No images are shipped and none are required to run the game; the maze, pellets,
ghosts, and HUD are built from Parts and text labels in code.

If you publish the game you will want a 512x512 game icon and a 16:9 thumbnail,
uploaded through the Roblox Creator Dashboard. Nothing in `src/` references image
assets, so there are no ids to fill in.
