# Image Assets

This directory contains image assets for PacBlox.

## Required Images

- **game_thumbnail.png** - Main game thumbnail (512x512)
- **icon.png** - Game icon (512x512) 
- **ui_background.png** - UI background pattern
- **particle_dot.png** - For pellet particle effects

## Asset Guidelines

- Use bright, contrasting colors for visibility
- Maintain retro/arcade aesthetic
- Keep file sizes reasonable for Roblox upload
- Use PNG format for transparency support

## Upload Instructions

1. Upload images to Roblox as Decal assets
2. Note the asset IDs for use in scripts
3. Reference in UI scripts as needed
